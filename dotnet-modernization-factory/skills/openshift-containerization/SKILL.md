# Skill: OpenShift Containerization

Generate resources only from the approved platform contract and organization-approved base images.
Check arbitrary UID/non-root compatibility, writable directories, listening port, readiness/liveness probes, resource requests/limits, ConfigMaps/Secrets, service routing, TLS termination, image policy, security scanning, and rollback.
Never hardcode credentials. Do not assume the application may run as root. Validate manifests against the target OpenShift cluster/version before deployment.
