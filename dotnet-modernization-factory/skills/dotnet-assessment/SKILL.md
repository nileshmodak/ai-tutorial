# Skill: .NET/IIS Assessment

Inspect `.sln`, `.csproj`, `packages.config`, `web.config`, `app.config`, source references, IIS settings, authentication, WCF, WebForms, System.Web, COM/GAC/registry usage, Windows services, filesystem paths, scheduled jobs, database providers, and test projects.

Output:
1. observed framework and hosting model;
2. dependency inventory;
3. Linux portability risks;
4. likely migration recipe and complexity;
5. evidence-linked blockers;
6. tests required to preserve behavior.

Do not equate a successful target-framework edit with a completed ASP.NET Core migration.
